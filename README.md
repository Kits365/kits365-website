# Kits365 — Site web

Kits365 propose des kits (solutions packagées) développés avec Microsoft Power Platform (Power Apps, Power Automate, Dataverse) pour les TPE/PME.

Ce dépôt contient le site statique d'entreprise construit avec Astro. Le site est en français et prêt à être déployé sur GitHub Pages.

Commandes utiles :

- `npm install` — Installe les dépendances
- `npm run dev` — Lance le serveur de développement local
- `npm run build` — Génère le site statique dans `./dist`

Déploiement : une action GitHub est fournie pour déployer automatiquement le contenu de `./dist` sur la branche `gh-pages`.
